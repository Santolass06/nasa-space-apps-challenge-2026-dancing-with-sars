# NASA Space Apps Challenge 2026 — Dancing with SARS

Project repository for the **NASA International Space Apps Challenge 2026**, challenge *Dancing with SARS*.

## Access

This repository is **public to view and clone**, but **write access (commits/pushes) is restricted to invited collaborators**.

- To contribute, ask a maintainer for an invitation.
- Everyone else is welcome to open an issue with suggestions.

## Getting started

```bash
git clone git@github.com:Santolass06/nasa-space-apps-challenge-2026-dancing-with-sars.git
cd nasa-space-apps-challenge-2026-dancing-with-sars
```
